# 招募接力｜GitHub Pages

這是靜態網站，不需要安裝套件、執行建置或設定伺服器。聯絡按鈕會開啟訪客的預設郵件程式，收件者為 gintingwu7@gmail.com。

## 發布到 GitHub Pages

1. 在 GitHub 建立一個新的儲存庫，例如 `recruit-flow`。GitHub Free 使用者可建立公開儲存庫。
2. 將本資料夾內的 `index.html`、`logo.svg`、`.nojekyll` 和 `README.md` 上傳到儲存庫的根目錄，不要把外層資料夾一起上傳。
3. 打開儲存庫的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
5. 選擇 `main` 分支及 `/(root)`，按 **Save**。稍等後可在 Pages 頁面找到網站網址。

一般專案網址為 `https://你的帳號.github.io/儲存庫名稱/`。實際網址請以 GitHub Pages 設定頁顯示為準。

## 修改

- 編輯 `index.html` 可修改文字、配色和寄信內容。
- `logo.svg` 是網站圖示；頁首標誌也包含在 `index.html` 中。
- 更新儲存庫中 `main` 分支的檔案後，GitHub Pages 會重新發布。

網站會公開給網路訪客瀏覽。郵件連結依賴訪客裝置已設定郵件應用程式；若未設定，可直接複製頁面上的電子郵件地址。
